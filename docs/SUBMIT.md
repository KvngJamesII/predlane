## Title

PredLane — Perps + Prediction Markets desk on Solana

## One-liner

Trade event markets and crypto perps in one Solana-native desk — demo works with zero wallet.

## Description

PredLane is a unified mobile-friendly trading desk for the Perps and Prediction Markets hackathon. Judges can browse mock prediction markets (macro, crypto, Solana) and live crypto perpetual marks, size YES/NO or Long/Short trades with leverage/margin previews, track open positions with unrealized PnL, and review closed-position realized PnL history — all persisted in localStorage with no wallet required.

Optional `@solana/wallet-adapter` (Phantom / Solflare) is present for future on-chain settlement demos but is never required to evaluate the product. Live perp marks use CoinGecko’s public API with graceful fallback to mocks plus in-app toast when offline.

**Why Solana:** sub-second settlement and cheap risk updates for perps, composable collateral/oracles/keepers on one L1, and the same Phantom/Solflare UX traders already use — 24/7 event + crypto markets without exchange hours.
